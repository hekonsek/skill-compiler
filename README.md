# skill-compiler: Compile source material into Agent Skills

An Agent Skill for compiling project knowledge into concise, portable [Agent Skills](https://skill.md/) files optimized for AI agents.

## Why this skill?

This skill turns human-friendly and project-specific source material into reusable agent instructions. It can compile:

- Architecture Decision Records and design documentation
- Instructions, runbooks, and policies
- Source code, tests, examples, and configuration
- Schemas, fixtures, and API contracts
- Project documentation

## Supported agents

This skill is intentionally tool-agnostic. It follows the portable [Agent Skills](https://skill.md/) format and does not require Codex, OpenAI, or any vendor-specific tooling.
